# 上游同步基线

这个目录存放**上游插件的原文快照**，用于「把上游改动合并进本仓库独立发行版」时的三方合并：

```
base   = .upstream/<插件目录名>/<文件>    ← 上次同步时的上游原文
ours   = plugins.v3/<插件目录名>/<文件>   ← 本仓库的独立发行版
theirs = 上游仓库最新 <文件>
```

合并由 `scripts/sync_maoyanrank.py` 执行，GitHub Actions 工作流
`.github/workflows/sync-maoyanrank.yml` 每天自动跑一次，检测到上游改动时开 PR。

- **不要手工修改这里的文件**：它由同步脚本在每次成功同步后自动推进。
- `meta.json` 记录上次同步的上游版本与时间。
- 基线也是「上游这次到底改了什么」的判定依据：只要上游文件与这里的快照一致，就认为没有更新。

文件按 LF 存储（与 git 仓库内的换行符一致），避免 CRLF 差异被误判成内容改动。
