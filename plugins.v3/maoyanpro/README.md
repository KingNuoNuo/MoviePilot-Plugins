# 猫眼榜单（MaoyanPro）

> [← 返回插件一览](../../README.md#插件一览) · 版本 v1.2.0 · 目录 `plugins.v3/maoyanpro`

猫眼榜单显示和订阅功能：按配置的榜单类型、平台和排名数量获取猫眼数据，识别媒体后添加订阅；
同时把抓取结果落成**榜单快照**，通过对外接口提供给 App、脚本与宿主推荐页。
**订阅与推荐页相互独立**：订阅勾了多少、甚至完全关掉订阅，推荐页/榜单接口都按自己的条数设置展示。

## 安装

MoviePilot →「设定 → 插件市场 → 添加市场」，填入
`https://github.com/KingNuoNuo/MoviePilot-Plugins`，保存后搜索「**猫眼榜单**」安装并启用。

本地部署也可把 `plugins.v3/maoyanpro` 整个目录拷贝到 MoviePilot 的插件目录
（容器内通常为 `/app/app/plugins/`，以你的实际部署为准），重启容器即可。

## 配置说明

订阅类型把**电影**与**剧集**分开设置，两组互不牵连。剧集只抓猫眼原生的
**电视剧+网剧综合榜**（官网的热度口径），不再单列电视剧榜 / 网剧榜；综艺同属剧集
大类（只是榜单独立），类型勾选也并入「剧集订阅类型」，只把**条数**留在下面单独配置：

| 配置 | 说明 |
| --- | --- |
| 电影订阅类型 | 电影票房榜单、网络电影榜单、影史总票房榜、国内年度票房榜、全球年度票房榜 |
| 剧集订阅类型 | 剧集综合榜单（电视剧+网剧）、综艺热度榜单 |
| 电影/剧集/综艺榜单订阅条数 | 各榜自动订阅的条数，可选项含 **0**（综艺条数独立于剧集条数） |
| 电影/剧集/综艺榜单推荐 | 推荐开关（v1.2.2 起）：开 = 按满榜抓取并展示（猫眼单个榜单最多 10 条），关 = 不展示 |
| 腾讯视频 / 爱奇艺 / 芒果TV / 优酷订阅条数 | 各平台细分榜的订阅条数，可选项含 **0** |
| 腾讯视频 / 爱奇艺 / 芒果TV / 优酷推荐 | 各平台细分榜的推荐开关（默认关） |
| 开放榜单接口 / 接入推荐页数据源 | 对外接口与宿主推荐页数据源的开关 |

**订阅看条数、推荐看开关**：

- **订阅条数 = 0** —— 不订阅该榜（仍会抓取并更新快照，推荐页照常展示）
- **推荐开关关闭** —— 推荐页与榜单接口不展示该榜（订阅不受影响）
- **订阅条数为 0 且推荐开关关闭** —— 该榜完全不抓取
- 每榜实际抓取 `max(订阅条数, 推荐)` 条（推荐开 = 10），订阅只取其中前「订阅条数」条

平台细分榜的**订阅条数**只服务自动订阅；**推荐开关打开**时该平台的剧集综合榜与
综艺榜才写入榜单快照（默认关，保持旧版行为）。

**影史总票房榜**（v1.2.2 起）是中国影史影片总票房排行榜（`piaofang.maoyan.com/rankings/year`，
服务端直出页面，含全部历史影片）：默认取前 30 条，条目带累计票房（如 154.46亿）与
上映日期。它没有订阅语义（上榜的都是老片），也不受订阅/推荐条数控制，勾选即抓取；
开启推荐数据源后会以「猫眼影史总票房」挂在推荐页的电影分类下。

**国内年度票房榜**（v1.2.2 起）与影史榜共用同一页面（`rankings/year?year=当前年份`），
返回当年国内年度票房排行（如 2025 年为疯狂动物城2、唐探1900 等），默认前 30 条，
同样没有订阅语义，勾选即抓取；开启推荐数据源后会以「国内年度票房」挂在推荐页的电影分类下。

**全球年度票房榜**（v1.2.2 起）是当年全球票房 Top 榜，数据取自 Box Office Mojo
（`boxofficemojo.com/year/world/{年份}/`，IMDb 系，服务端直出页面）：默认取前 30 条，
条目带全球累计票房（美元口径，如 25.14亿美元）。猫眼网页端无全球票房数据（专业版
App 独有、接口需签名），因此该榜与猫眼数据相互独立，同样没有订阅语义，勾选即抓取；
开启推荐数据源后会以「全球年度票房」挂在推荐页的电影分类下。片名为英文原名，插件会在
媒体识别时把 TMDB 中文名写入条目的 `title_cn` 字段（`/rank` 返回），`/rank-list`
与推荐页则直接优先展示中文名。

推荐页主界面只挂 **3 个全网数据源**（电影票房 / 剧集综合热度 / 综艺热度），保持版面
简洁（勾选影史总票房榜 / 国内年度票房榜 / 全球年度票房榜时会分别追加
「猫眼影史总票房」「国内年度票房」「全球年度票房」源）；
平台细分榜不单独挂源，而是
编进「猫眼剧集综合热度」「猫眼综艺热度」的**「更多」
页**：`/rank-list` 不带 `platform` 参数时按页返回——第 1 页全网榜，第 2 页起依次返回
有数据的平台榜（腾讯视频 / 爱奇艺 / 芒果TV / 优酷），平台条目标题带「（平台名）」
后缀便于区分。

## 对外接口

注册在宿主 `/api/v1/plugin/MaoyanPro` 前缀下，`/rank` 与 `/rank-list` 都用宿主的
**`bear` 模式**认证（依赖 `verify_token`），即三种凭据任选其一：

- App 登录态的 **JWT**：`Authorization: Bearer <access_token>`
- **API 令牌**：`X-API-KEY: <API_TOKEN>` 头，或 `?apikey=<API_TOKEN>` 查询参数
- `?token=<API_TOKEN>` 查询参数

> 注意：宿主默认的 `apikey` 模式只认 API 令牌，用账号密码登录的 App 会 401，
> 所以 `/rank` 显式声明了 `auth="bear"`，两种模式都能读。

| 接口 | 返回 | 说明 |
| --- | --- | --- |
| `GET /rank` | `Response[MaoyanProSnapshot]` | 榜单快照，含名次、类型、平台、票房/热度、媒体身份与海报 |
| `GET /rank-list` | `Response[List[MediaInfo]]` | 推荐页 / 浏览页数据源，声明 `page` 参数 |
| `GET` `POST /refresh` | `MaoyanRefreshResult` | 立即触发一次抓取与订阅 |

`/rank` 支持四个可选参数：

- `board_type`：`movie`（电影票房）、`total`（影史总票房）、`year`（国内年度票房）、
  `global`（全球年度票房）、`web-movie`（网络电影）、`web-all`（剧集综合榜：
  电视剧+网络剧）、`zongyi`（综艺热度）
- `board`：榜单名关键字，如 `腾讯视频`
- `limit`：每个榜单最多返回的条目数，用于限制响应体大小
- `platform`：猫眼 `platformType`（`3` 腾讯视频 / `2` 爱奇艺 / `7` 芒果 / `1` 优酷），
  只返回该平台的细分榜；不传时返回全部榜单

```bash
curl "http://<MP>:3000/api/v1/plugin/MaoyanPro/rank?apikey=<API_TOKEN>&limit=5"
curl "http://<MP>:3000/api/v1/plugin/MaoyanPro/rank?apikey=<API_TOKEN>&board_type=web-all"
curl -H "Authorization: Bearer <access_token>" \
     "http://<MP>:3000/api/v1/plugin/MaoyanPro/rank?board_type=zongyi"
curl -X POST "http://<MP>:3000/api/v1/plugin/MaoyanPro/refresh?apikey=<API_TOKEN>"
```

响应为宿主统一三段式 `{ success, message, data }`，`data.boards[].items[]` 即榜单条目。
**未识别到媒体的条目仍会返回**（身份字段为空），便于调用方先渲染榜单。

## 接入宿主推荐页（可选）

配置中打开「接入推荐页数据源」后，插件通过 `ChainEventType.RecommendSource`
把已配置的榜单注册到宿主推荐页：电影票房进「电影」分类，
剧集综合 / 综艺热度进「电视剧」分类；平台细分榜不注册独立数据源，
统一编进全网源的「更多」页（见上文「推荐页排版」）。
注册是**叠加**到事件数据，不会影响其它插件的数据源。订阅总开关关闭时推荐源照常有效。

## 插件详情页

宿主插件管理页点开插件即可看到详情页（`get_page`），自上而下三块：

1. **MoviePilotApp 推荐卡**：置于页面最顶部，附 GitHub 仓库地址外链；
   插件设置页（`get_form`）顶部展示同一张卡片。
2. **实时榜单**：直接读快照，按榜单类型分区展示（电影票房 / 影史总票房 / 国内年度票房 /
   全球年度票房 / 网络电影 / 剧集综合 / 综艺热度，快照里存在哪个类型就出现哪个分区），
   每榜展示前 10 条，标题识别到 TMDB 时可点击跳转；右上角「刷新榜单」触发一次立即抓取，
   完成后自动重载页面。平台细分榜不占分区，只展示各自主榜。
   剧集 / 综艺的热度是猫眼 PUA 加密字体，抓到的是乱码，页面改显上线天数。
3. **订阅历史**：统计卡 + 分页卡片，与旧版一致。

## 快照与兜底

- 每次刷新把榜单落成插件数据 `snapshot`（含逐条回填的媒体来源、ID、海报、简介、年份）。
- **抓取全失败时保留上一次快照**，避免异常时段接口返回空数据。
- 升级后尚未跑过刷新时，`/rank` 回退到订阅流水并在 `message` 中注明，保证接口始终可用。
- `/rank-list` 会过滤掉没有媒体身份的条目，因为它们无法被宿主识别为媒体。

## 异常处理

- 上映信息为空或为未知文案时，使用未知年份继续识别；明确上映日期、已上映天数和首日文案按对应规则解析。
- 剧集综合榜（不传 `seriesType`，官网返回电视剧+网络剧综合榜）与综艺（`seriesType=2`）使用官网当前热度接口，按北京时间查询当天榜单，保留各平台筛选。每轮刷新复用一个官网浏览器会话，由页面脚本处理请求校验。
- 浏览器启动或页面加载失败时，继续尝试无 Cookie 请求未处理榜单；热度接口需要页面校验，此时可能仍返回 403。失败来源会明确记录，不影响其他来源继续处理。
- 一个来源请求失败、返回非 JSON 或响应结构异常时，记录来源地址并继续其他榜单。
- 榜单内的无效条目、单条媒体识别或订阅异常只影响该条目，日志标明来源排名或媒体标题。
- 跳过坏条目后不补取配置排名范围之外的内容；保留跨平台剧集去重，成功订阅的条目仍保存历史。

出现部分失败后，可从日志中的来源地址、排名和媒体标题定位问题；“刷新完成”表示本轮遍历结束，不代表所有来源都成功。
